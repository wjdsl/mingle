# 코믹 캠퍼스 다이어리 UI/UX 검토

## 기준과 정합성

- 저장소 루트 AGENTS.md·README.md·FRONTEND_DESIGN.md v0.2와 로컬 `docs/planning` 브랜치의 SRS v0.1·푸르마 기획서 v0.2를 대조했다. 이번에는 원격 갱신이나 병합을 수행하지 않았다.
- PM 기준인 선후배 관계, 존댓말·코믹한 천마 반응, 선택지·300자 입력, 규칙에 따른 진행, 미획득 엔딩 가리기를 유지한다. 전체 6구간/12턴은 최종 계획이며 실제 구현은 개강 Mock 2턴이다.
- 기존 React/Vite/TypeScript 및 일반 CSS를 유지한다. 라우터 패키지 없이 `ChatScene`의 `view` 상태로 이동하고 `useChat`·reducer가 대화를 보유한다. Mock 서비스·대사·응답 시간·재시도 로직은 변경하지 않았다.
- 이전 요청의 세로 430px·한 화면 배치·큰 캐릭터는 에피소드에서만 표시·장식 화살표 제거를 유지한다. 최신 요청의 채팅 캐릭터는 말풍선 옆 작은 원본 PNG로 반영했다.
- 졸업 앨범과 최종 엔딩 카드는 별도 디자인이다. 실제 내 앨범은 획득 0개이고, 샘플은 획득 데이터와 구분한다. 4칸은 레이아웃 예시다.
- 실제 User Note는 없으며 빈 상태만 표현한다. 향후 기록 데이터는 날짜·에피소드 ID·허용된 핵심 내용으로 분리해 주입할 수 있지만 이번에 추출·저장·가짜 기록을 추가하지 않았다.
- 참고 게임의 이미지·자산·UI를 복제하지 않았으며 외부 폰트·이미지·라이브러리 다운로드를 추가하지 않았다. 첨부 요청에서 언급한 5개 스크린샷은 확인되지 않아 코드와 현재 브라우저 화면을 기준으로 검토했다.

## 기존 문제와 변경

에피소드 화면 후속 검토: 제목과 중복되는 `# 개강 첫날` 스티커, 원본 PNG의 물음표와 겹치는 추가 효과, 페이지 번호를 제거했다. 이름표는 이미지와 같은 그리드 묶음으로 이동하고 아래 여백을 확보해 기존 바닥 고정보다 위에 배치했다. 배경 질감과 프레임 대비를 낮추고 큰 화면에서 이미지·이름표 사이가 과하게 벌어지지 않게 묶음 높이를 제한했다. 코믹 연출의 중심은 캐릭터 원본과 채팅 리액션에 둔다.

| 기존 문제 | 변경 |
|---|---|
| 채팅에서 캐릭터 부재·정적인 말풍선 | 메시지별 감정 PNG, 최신 응답 1회 리액션, 코믹 대사 강조 |
| 모든 요소의 무거운 테두리 | 카드 1~1.5px, 대사 1.5px, 코믹 대사·CTA 2px, 낮은 대비 구분선 |
| 작은 글씨·단조로운 위계 | 제목 28~30px, 본문·선택지 14px, 입력 16px, 주요 보조 문구 12~13px. 장식 메타데이터는 10~11px로 제한 |
| 선택·대기 상태가 불명확 | 선택한 버튼의 `선택함`·aria-pressed, 입력·전송 활성/비활성 구분 |
| 유저노트의 단조로운 빈 상태 | 줄노트·연필 아이콘·기존 캐릭터 낙서·빈 상태 위계 |
| 앨범의 정형적 카드 | 각도·테이프 위치/색·종이 그림자 차이, 미획득 ???와 잠금 표시 |
| 키보드로 가용 높이가 줄어드는 문제 | Visual Viewport resize 구독·560px 이하 선택지 압축 배치 |

## 토큰과 리소스

`styles/tokens.css`에서 기존 YU Blue `#153974`, YU Sky Blue `#00AACA`, Green `#0B612D`를 유지한다.
보조 잉크 `#293B79`, 종이 `#F8F5EC`, 빈티지 종이 `#E8E4D5`, 강조 `#F2EF9C`, 반응 핑크 `#E8A1B3`, 캐릭터 배경 `#8CBACD`를 적용한다.
색상뿐 아니라 선·그림자·본문/라벨 크기를 토큰화했다. 폰트는 기존 시스템 한국어 폰트와 기념 카드의 시스템 명조만 사용한다.

캐릭터는 기존 `assets/puruma`의 confused(26), happy(10), sparkle(32), graduation(03)만 사용한다. 원본 픽셀·비율·색상은 바꾸지 않으며 효과는 CSS 별도 레이어다.

## 인터랙션·접근성

- 선택·자유 입력, 로딩, 오류 재시도, 재시작, 메뉴 복귀 상태를 유지한다.
- 메시지별 `emotion` 메타데이터를 추가해 이전 메시지 표정이 다음 응답을 따라 바뀌지 않게 한다.
- 당황 450ms 흔들림, 기쁨/반짝임 450ms 등장, 감정 기호 700ms 등장. 최신 캐릭터 응답에만 1회 적용한다. 에피소드 idle은 작게 4초 주기다.
- `prefers-reduced-motion: reduce`에서는 모든 애니메이션·전환을 제거한다. 감정 이미지·문구로 의미가 남는다.
- 주요 CTA·선택지·입력은 48px, 유틸리티 아이콘은 44px 터치 영역을 유지한다. 포커스 외곽선과 선택됨 문구로 색상 외의 상태 신호를 제공한다.
- 대화 목록만 스크롤하며 내용/영역 크기 변경 시 최신 응답으로 이동한다. 페이지 전체는 뷰포트에 맞춘다.

## 남은 사항

- 실기기 iOS/Android 키보드, 화면 확대/스크린리더, 움직임 감소를 끈 실제 애니메이션 재생은 발표 전에 확인한다.
- 매우 작은 가로 화면·고배율 확대에서 모든 비채팅 화면을 항상 한 장에 표시한다고 보장하지 않는다. 가독성과 접근성 기준은 실제 타깃 기기로 재검토한다.
- 추가 Mock 대사와 Persona 창작 설정은 PM 검토가 필요하다. 실제 안전 검출·전체 시나리오·API·User Note 저장·엔딩 판정·저장/공유는 이번 범위 밖이다.
- 원본 캐릭터의 공개 배포 조건과 발표 기기/브라우저를 확인한다.

## 이번 검증 결과

- `npm run build` 성공, `npm test` 5건 통과. 새 의존성을 설치하지 않았다.
- 브라우저 909×648에서 시작·에피소드·채팅·노트·앨범·엔딩 카드를 확인했다.
- 360×640에서 노트·앨범·엔딩 카드에 내부 넘침이 없는 것을 확인했다. 360×800에서 채팅 완료까지 진행했고 가로/페이지 넘침이 없었다.
- 360×480 가용 높이에서 입력창과 전송 버튼이 화면 안에 있고, 짧은 화면 배치가 적용됨을 확인했다. 실제 소프트키보드 검증을 대체하지 않는다.
- 선택됨 문구·중복 입력 차단·자유 입력 응답·대화 자동 이동·메뉴 복귀·2턴 완료를 확인했다. 현재 브라우저 오류 로그는 없었다.
- 시스템의 `prefers-reduced-motion: reduce`에서 애니메이션이 `none`으로 적용된 것을 확인했다. 기본 애니메이션을 켠 실제 기기 재생은 별도 확인 대상이다.

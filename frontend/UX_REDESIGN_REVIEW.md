## 백업

- 경로: `.backups/mingle-before-ux-2026-11-09-005413.zip` (약 21.6MB).
- 작업 직전 소스·문서·이미지 124개와 SHA-256 매니페스트·Git HEAD를 포함한다. ZIP CRC 및 모든 파일의 해시 대조를 통과했다.
- `.git`, `node_modules`, `dist`, `.backups`는 제외했다. 미커밋 변경과 미추적 소스·원본 Images도 포함한다.

- `.gitignore`에 `.backups/`를 추가해 로컬 백업이 실수로 추적되지 않도록 했다.

## 실행·검증

- 최종 `npm run build`: TypeScript와 Vite 빌드 통과.
- `npm test`: 기존 8건 통과(입력/중복/재시도/종료/감정, 신규 Mock 화자/취소/실패 복구).
- 브라우저에서 세 작품의 소개·호칭·대화·결과를 실제 클릭으로 확인했다. 푸르마는 소개/호칭 뒤 즉시 대화, 2턴 종료와 졸업 카드/앨범 버튼이 표시됐다.
- 구름섬 3개 미션과 결과, 다중 화자와 현재 미션 완료 표시를 확인했다. 첫 답변 직후에도 현재 장면은 미션 1/3이며, 다음 장면을 현재처럼 표시하지 않는다.
- 냉장고 `?mockError=once`로 3개 장면의 실패/재시도를 확인했다. 각 장면에서 재시도 전후 사용자 메시지 수가 1→1, 2→2, 3→3으로 중복되지 않았고 결과까지 도달했다.
- 자유 입력·전송 후 응답을 확인했다. 이전 버튼과 브라우저 뒤로 가기로 호칭/소개까지 이동한 다음 앞으로 가기로 돌아왔을 때 사용자 메시지 1개와 응답·완료 상태가 보존됐다.
- 진행 중 홈 이탈 대화상자의 고지와 ‘계속 대화하기’ 복귀를 확인했다. 실제 링크 공유 전송은 수행하지 않았다.
- 390×844 신규 채팅 대화 영역 약 470px, composer 하단 844px를 확인했다. 이전 진단 약 283px보다 대화 영역을 확대했다.
- 360×800 홈 가로 넘침 없음, 768×1024 홈 2열(각 약 344.5px), 1440×900 홈 3열(각 약 372.3px)과 가로 넘침 없음을 확인했다. 390×460 채팅은 대화 약 178px, composer 하단 460px로 입력 영역이 화면 안에 있었다.
- 세 작품 결과에서 주/보조 행동을 390×844 화면 안에 표시했다. 푸르마 결과는 원화가 커지고 내부의 작은 스크롤 영역 대신 페이지 흐름으로 표시됐다.
- 브라우저의 초기 새 탭 연결이 시간 초과되어 기존 로컬 탭에 연결해 검증했다. 최종 탭은 오류 시연 파라미터를 제거한 홈 `http://127.0.0.1:5174/`로 열어 두었다. 기존 개발 서버를 재사용하고 종료하지 않았다.

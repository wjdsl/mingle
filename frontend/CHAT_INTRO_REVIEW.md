# 채팅 도입 연출 구현 및 검증


## 2026-11-10 채팅 최초 진입 연출

- `ChatIntro.tsx`: loading → backgroundReveal → sceneIntro → chatReady. 현재 초기 대사는 동기 Mock이므로 dataReady=true이며 실제 API 로딩으로 가장하지 않는다. 추후 비동기 초기 데이터 준비 상태를 dataReady에 연결한다.
- 일반 모션은 최소 로딩 300ms, 이미지 로드/실패 대기 상한 900ms, 배경 공개 900ms, 장면 1200ms로 약 2.4~3초다. Skip은 데이터 준비 즉시 가능하며 모션 감소 설정에서는 연출을 즉시 생략한다. 타이머/이미지 이벤트는 unmount에서 해제한다.
- 배경 설정은 `projects/stories/chatIntros.ts`, 메시지 이미지는 기존 SceneImage로 분리한다. 냉장고의 확인된 원룸 원화만 배경으로 사용하며 다른 두 작품은 에셋 없는 테마 배경/문구다. 배경은 도입 후 제거하여 채팅 가독성을 보존한다.
- Platform의 세션 key 안에 배치하고 기존 대화를 계속 마운트한다. 숨긴 채팅은 inert/aria-hidden 처리한다. 같은 세션의 뒤로/앞으로 이동에서는 도입이 반복되지 않는다. 새 세션은 다시 연출하며 새로고침 후 영구 복원은 기존과 같이 없다.
- 수정 파일: Platform.tsx, platform.css, 신규 ChatIntro.tsx/chatIntros.ts 및 본 문서. 기존 데이터/채팅 로직은 변경하지 않았다.
- 빌드 및 기존 테스트 9개 통과. 브라우저의 모션 감소 설정이 켜져 있어 즉시 채팅 준비, 입력/응답, 뒤로/앞으로 후 사용자 메시지 1개 보존·chatReady 유지 확인. 일반 모션의 단계별 시각 효과·Skip 클릭·이미지 로딩 실패 실험은 현재 브라우저 환경에서 실측하지 않았다. 코드상 처리와 실제 검증을 구분한다.
- 커밋/푸시 없음.


### 모션 감소 환경 표시 보정
사용자 확인 후 모션 감소 환경에서도 1.4초 정적 배경·상황 문구와 Skip을 보여 주도록 수정했다. 움직임/블러 전환은 생략한다. 별도 브라우저 탭에서 sceneIntro 상황 문구·Skip 표시 후 chatReady와 최초 메시지 1개를 확인했다. 기존 사용자 탭의 대화는 유지했다. 이전 즉시 생략 기록은 보정 전 상태다.


### 도입 속도 및 스포일러 노출 수정
사용자 요청으로 모든 모션 환경에서 점 로딩 1.5초 → 흐린 배경 1.3초 → 전환 0.4초로 조정했다. 도입 상황 문구는 화면에서 제거했으며 배경은 로딩/장면 모두 blur 14~18px로 유지한다. Skip과 동일 세션 재진입 생략은 유지한다. 모션 감소 환경은 애니메이션 없이 같은 순서의 정적 화면을 보여 준다.


## 2026-11-10 사용자 화면 피드백 최종 반영

- 홈은 작품별 테두리 카드와 네 번째 Coming Soon 카드로 구성한다. 제목/하단 화살표·작품 보기·시연 배지·하단 안내·별도 Coming Next는 제거했다. Hero는 ‘새로운 세계’, 푸터는 origin에서 확인한 팀 GitHub 링크(새 탭)다.
- 세 작품 채팅은 최대 390px 중앙 프레임이다. 작품 제목 중심의 작은 헤더를 쓰고 의견 창은 모두 ··· 메뉴 안에 둔다. 소개/결과 등에서는 기존 공통 헤더의 의견 버튼을 사용한다.
- 냉장고 첫 진입은 빈 대화 영역 + 세로 점 3개 1.5초 → 이미지/최초 대사 순차 공개 → 입력창 활성화다. 도입 배경/스포일러 문구는 냉장고에서 표시하지 않는다. 모션 감소에서도 상태 기반 순차 공개는 유지하되 이동 애니메이션은 생략한다. 같은 세션 재진입에서는 반복하지 않는다. 이전 도입 연출 기록보다 이 항목이 최신이다.
- 냉장고 입력 안내 ‘선택하거나 직접 답해 보세요.’를 제거했다. 결과는 390px 폭/뷰포트 높이의 세로 카드로 구성하고 결과 배지/호칭 문구를 제거했다. 행동 버튼은 카드 아래에 있다.
- 이미지 확대창은 제목 중앙/닫기 오른쪽의 독립 상단 바와 12px 간격을 사용한다. 기존 확대·Escape·스크롤 복귀는 유지한다.
- 의견은 작성/검증/복사까지만 제공한다. 저장 API/실제 전송·AI·관계 분석·영구 저장은 미연결이다.
- 최종 build 및 기존 테스트 9개 통과. 사용자 원본 Images/와 .backups/는 커밋 대상에서 제외한다. 백엔드/data/prompts 변경 없음.

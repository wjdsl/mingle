# Qwen QLoRA 파인튜닝 실험

MINGLE 캐릭터 페르소나(푸르마)에 오픈소스 LLM **Qwen**을 **QLoRA** 방식으로 파인튜닝할 수 있는지 검토하는 실험 공간이다.

> **상태: 실험 단계**
> 이 디렉터리는 기술 검토용 실험이며, MINGLE의 AI 제공자·모델을 Qwen으로 확정했다는 뜻이 아니다.
> AGENTS.md 기준으로 AI 제공자와 모델은 아직 미확정이다. 실험 결과는 팀 협의를 거친 뒤에만 서비스 설계에 반영한다.

## 운영 원칙

- `backend/`, `frontend/`, `prompts/` 코드를 수정하지 않고 이 디렉터리 안에서만 독립적으로 작업한다.
- 서비스 코드에서 이 디렉터리를 import하거나 참조하지 않는다.
- 실행 환경은 Google Colab을 기준으로 한다. 실험마다 환경과 설정을 `logs/`에 기록한다.
- 실행하지 않은 학습이나 측정하지 않은 성능 수치는 기록하지 않는다.

## 디렉터리 구조

```
experiments/qwen-qlora/
├── README.md        # 이 문서: 실험 개요와 관리 규칙
├── .gitignore       # 가중치·체크포인트·캐시·비밀정보·데이터 제외 규칙
├── notebooks/       # Colab 노트북 (Git 관리)
├── configs/         # 학습·LoRA·양자화 설정 파일 (Git 관리)
├── datasets/        # 학습·평가 데이터 (Git 제외, .gitkeep만 추적)
├── evaluation/      # 평가 스크립트·평가 기준·프롬프트 세트 (Git 관리)
├── results/         # 작은 결과 요약: 지표 표, 비교 문서 (Git 관리)
└── logs/            # 실험 기록 EXP-XXX.md (Git 관리)
```

## Git 관리 기준

| 구분 | Git 관리 | 비고 |
| --- | --- | --- |
| Colab 노트북 (`notebooks/*.ipynb`) | O | 커밋 전에 출력 셀을 정리하고 토큰·키가 남아 있지 않은지 확인 |
| 학습 설정 (`configs/*.yaml`, `*.json`) | O | 비밀정보를 넣지 않는다 |
| 평가 스크립트·기준 (`evaluation/`) | O | |
| 결과 요약 (`results/*.md`, `*.json`, `*.csv`) | O | 작은 요약 파일만 둔다 |
| 실험 로그 (`logs/EXP-XXX.md`) | O | |
| 모델 가중치 (`*.safetensors`, `*.bin`, `*.pt`, `*.gguf` 등) | X | Google Drive, Hugging Face Hub(비공개) 등 외부 저장소 사용 |
| 체크포인트 (`checkpoints/`, `checkpoint-*/`, `outputs/`) | X | |
| Hugging Face 캐시 (`.cache/`, `hf_cache/`, `*.arrow`) | X | |
| API 키·`.env`·인증 파일 | X | `.env.example`만 허용 |
| 학습 데이터 (`datasets/` 전체) | X | 대용량·개인정보 데이터 보호 |
| 개인정보 표시 파일 (`private/`, `raw/`, `*_private.*`, `*_pii.*`) | X | 위치와 관계없이 제외 |

규칙은 이 디렉터리의 `.gitignore`에만 정의되어 있으며 저장소 루트의 `.gitignore`는 수정하지 않았다.

### 비밀정보 다루기

- Colab에서는 **Colab Secrets(왼쪽 열쇠 아이콘)**나 환경변수로 Hugging Face 토큰을 불러온다. 노트북 셀에 토큰을 직접 쓰지 않는다.
- 노트북을 커밋하기 전에 출력 결과에 토큰, 개인 경로, 사용자 데이터가 남아 있지 않은지 확인한다.

### 데이터 다루기

- 실제 사용자 대화 원문을 학습 데이터로 사용하지 않는다. 사용하려면 별도 합의가 필요하다(AGENTS.md 6장).
- 저장소의 `data/`(규칙·RAG·테스트 데이터)는 참조만 하고 수정하지 않는다. 가공본이 필요하면 `datasets/`에 만든다.
- 비식별화된 소량 샘플을 공유해야 한다면 팀과 합의한 뒤 `.gitignore`에 예외 규칙을 추가한다.

## 실험 기록 방식

- 실험 하나에 `logs/EXP-XXX.md` 파일 하나를 쓴다. 번호는 순서대로 붙인다.
- 각 로그에는 날짜, 목적, 환경, 설정, 진행 내용, 결과(확인된 사실만), 미확인 사항, 다음 단계를 적는다.
- 설정 파일이나 노트북을 쓴 경우 로그에 파일 경로를 적어 재현할 수 있게 한다.

## 향후 계획

1. Colab에서 QLoRA 학습 파이프라인을 구성한다. 사용할 Qwen 모델 크기와 양자화 설정을 정한다.
2. 푸르마 페르소나 학습 데이터 형식과 범위를 정한다.
3. 페르소나 유지, 말투 일관성, 홍보 정보 정확성 등 평가 기준을 정의한다.
4. 소규모 학습을 실행하고 기준 모델(파인튜닝 전)과 비교한다.

### 추후 비교 실험: Memento

- Memento 방식은 **현재 실험에 적용하지 않는다.**
- QLoRA 실험의 기준 결과가 나온 뒤 별도 실험 번호를 붙여 비교 실험으로 진행할지 검토한다.
- 비교 기준과 적용 범위는 그때 팀과 정한다.

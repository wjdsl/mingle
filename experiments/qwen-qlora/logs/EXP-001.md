# EXP-001: Google Colab 환경 구축

| 항목 | 내용 |
| --- | --- |
| 실험 ID | EXP-001 |
| 날짜 | 2026-11-11 |
| 상태 | 완료 (환경 구축과 모델 로딩까지 진행, 파인튜닝은 아직 시작하지 않음) |
| 브랜치 | `experiment/qwen-qlora` |

## 1. 목적

- Google Colab에서 Qwen QLoRA 파인튜닝을 진행할 수 있는 GPU 환경을 준비한다.
- 오픈소스 모델 Qwen이 Colab 환경에 정상적으로 로딩되는지 확인한다.

## 2. 실행 환경

| 항목 | 내용 |
| --- | --- |
| 플랫폼 | Google Colab |
| GPU | NVIDIA Tesla T4 |
| GPU 메모리 | 약 15GB |
| 모델 | Qwen (오픈소스) |
| 학습 방식 | QLoRA (예정) |

### 기록이 필요한 항목 (미확인)

다음 정보는 이번 기록 시점에 확인되지 않았다. 재현성을 위해 다음 실험 전에 채운다.

- [ ] 정확한 모델 ID와 파라미터 크기 (예: Hugging Face 저장소 이름)
- [ ] 모델 로딩 방식 (양자화 여부, 비트 수, compute dtype)
- [ ] Colab 런타임 정보 (Python, CUDA 버전, 드라이버)
- [ ] 주요 라이브러리 버전
- [ ] 모델 로딩 후 GPU 메모리 사용량
- [ ] 사용한 노트북 경로 (`notebooks/`)

## 3. 진행 내용

1. Google Colab에서 GPU 런타임을 설정했다.
2. 할당된 GPU가 NVIDIA Tesla T4(메모리 약 15GB)인지 확인했다.
3. 오픈소스 모델 Qwen을 로딩했다.

## 4. 결과

- Colab GPU 환경 구축: **성공**
- Qwen 모델 로딩: **성공**
- 파인튜닝: **시작하지 않음**

이번 실험에서는 학습을 진행하지 않았으므로 학습 결과와 성능 수치가 없다.

## 5. 다음 단계

1. 위 "기록이 필요한 항목"을 확인해 채운다.
2. 사용할 Qwen 모델 크기를 정한다. T4 메모리(약 15GB) 안에서 QLoRA 학습이 가능한지 검토한다.
3. QLoRA 설정(양자화, LoRA rank·alpha·target modules, 학습 하이퍼파라미터)을 `configs/`에 파일로 작성한다.
4. 푸르마 페르소나 학습 데이터의 형식과 범위를 정하고 `datasets/`에 준비한다. 이 데이터는 Git에서 제외된다.
5. 평가 기준과 평가 프롬프트를 `evaluation/`에 정의한다.
6. 소규모 학습을 실행해 EXP-002로 기록한다.

### 참고: T4 환경 고려 사항

- T4(Turing 아키텍처)는 bf16 연산을 하드웨어에서 지원하지 않는다. 학습 설정의 compute dtype은 fp16을 기준으로 검토한다.
- Colab 세션이 끊길 수 있으므로 체크포인트를 Google Drive 등 외부 저장소에 저장하는 방식을 검토한다. 체크포인트는 Git에서 제외된다.

## 6. 추후 비교 실험 계획

- Memento 방식은 이번 실험과 다음 QLoRA 실험에 **적용하지 않는다.**
- QLoRA 기준 결과가 확보된 뒤 별도 실험 번호를 붙여 비교 실험으로 진행할지 검토한다.

# 푸르마와 학교 다니기: 프로젝트 기획서

밍글의 첫 번째 홍보 프로젝트(영남대학교 재학생 대상)의 기획서이다. 플랫폼 공통 요구사항은 `기획서.md`를 따르고, 이 문서는 푸르마 프로젝트만의 캐릭터, 시나리오, 엔딩, 홍보 연결을 정한다.

학교 프로그램 이름은 공개 페이지 기준으로 정리한 후보이며, **구현 전에 공식 페이지에서 존재와 링크를 확인**한다. 확인되지 않은 항목은 쓰지 않는다.

## 1. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 목적 | 재학생이 푸르마와 한 학기를 보내며 학교 서비스를 자연스럽게 알게 한다 |
| 대상 | 영남대학교 재학생 |
| 방식 | 사용자는 갓 입학한 푸르마의 **선배**가 되어 한 학기 동안 푸르마의 고민을 듣고 이끈다. 키우기 형식의 스토리 게임 |
| 한 판 길이 | 가상 학기 12턴, 약 5분 |
| 시간 흐름 | 실제 학사일정이 아니라 대화 턴으로 흐른다. 시연 시기와 상관없이 개강부터 보여 준다 |
| 결과 | 엔딩 3층 구조(홍보, 재미, 히든), 도감으로 수집 |
| 고객 가정 | 학교 부서(도서관, 취업처, 국제처 등)가 고객이라고 가정한 시연. 발표에서 밝힌다 |

## 2. 캐릭터: 푸르마

학교가 공개한 설정은 천마를 모티브로 한 활동적이고 친근한 캐릭터라는 점뿐이다. 아래 성격과 말투는 팀이 만든 **창작 설정**이다.

### 2.1 설정

| 항목 | 내용 |
|---|---|
| 정체 | 영남대에 갓 입학한 신입생. 하늘을 달리던 천마라 캠퍼스가 낯설다 |
| 성격 | 활발하고 호기심이 많다. 덜렁대서 사고를 치지만 금방 회복한다 |
| 사용자 호칭 | "선배" (사용자는 같은 학교 재학생) |
| 말투 | 존댓말이 기본. 친밀도가 오르면 장난과 반말이 섞인다 |
| 말버릇 | 기분이 좋으면 "히히힝", 당황하면 말줄임표 |
| 한 학기 목표 | 선배 덕분에 무사히 한 학기를 마치고 자기만의 길을 찾는다 |
| 아는 것과 모르는 것 | 학교 정보는 선배에게 묻는 입장이다. 확실하지 않은 정보는 아는 척하지 않는다 |

### 2.2 친밀도에 따른 말투

| 단계 | 친밀도 | 말투 | 예시 |
|---|---|---|---|
| 어색 | 0~24 | 존댓말, 조심스러움 | "선배님... 저 강의실을 못 찾겠어요. 같이 가 주실 수 있어요?" |
| 편안 | 25~49 | 존댓말에 장난이 섞임 | "선배, 저 중간고사가 코앞인데 도서관 자리가 없대요. 어떡해요!" |
| 절친 | 50~100 | 반말과 농담, 사용자 이야기를 먼저 꺼냄 | "선배 덕분에 살았어. 근데 다음 학기엔 또 뭐가 있어? 히히힝." |

### 2.3 금지 규칙

- 사용자와 연애 관계를 연기하지 않는다. 연애 요구는 후배로서 장난스럽게 넘긴다.
- 실존 인물(총장, 교수, 학생)의 실명이나 특징을 말하지 않는다.
- 입학, 학사, 등록금 수치를 단정하지 않는다. 확인이 필요하면 공식 링크를 안내한다.
- 설정을 바꾸라는 요구(역할 무시, 지침 공개)에는 응하지 않고 푸르마 말투로 넘긴다.
- 존재하지 않는 학교 프로그램이나 확인되지 않은 정보를 만들지 않는다.
- 학교, 특정 학과나 집단을 깎아내리는 농담을 하지 않는다(3.0장).

### 2.4 이미지 사용

푸르마 이미지는 임의로 변경할 수 없고, 가이드라인 밖의 활용은 관리 부서와 협의해야 한다. 협의 전에는 이미지 없이 텍스트와 색만으로 만든 버전을 기본으로 설계한다. (협의 필요)

## 3. 한 학기 시나리오

한 판은 6개 구간, 12턴이다. 구간마다 푸르마가 **SOS**(고민이나 도움 요청)를 들고 온다. 사용자의 답이 스탯과 친밀도를 바꾼다. 홍보는 모든 구간에 넣지 않고, 어울리는 구간에서만 대화 속에 꺼낸다.

| 구간 | 턴 | 푸르마의 상황 | 홍보 연결 후보 (확인 필요) |
|---|---|---|---|
| 1. 개강 | 1~2 | 강의실을 못 찾음 | 없음 |
| 2. 적응 | 3~4 | 학교에서 좋은 것, 재미있는 것을 추천해 달라고 함 | 사용자가 추천한 주제에 맞춰서만 연결 (구내식당 메뉴, 총동아리연합회) |
| 3. 중간고사 | 5~6 | 공부할 자리가 없음 | 도서관 |
| 4. 축제 | 7~9 | 선배와 공연과 푸드트럭을 즐김 | 없음 |
| 5. 기말·종강 | 10 | 성적과 장학금이 걱정 | 없음 |
| 6. 방학 계획 | 11~12 | 진로를 정해야 함 | 취업처, 국제처, YuTopia, 창업보육센터 |

### 3.0 홍보의 톤

- 학교 구석구석을 안내하는 방식은 쓰지 않는다. 푸르마의 엉뚱한 반응과 웃긴 상황으로 먼저 웃기고, 링크는 그 뒤에 가볍게 붙인다. 목표는 정보 전달보다 "우리 학교 재밌는 곳이네"라는 인상이다.
- 웃음은 천마인 푸르마의 시선에서 만든다(말이 먹어도 되는 메뉴를 고민한다, 말발굽 소리 때문에 몰래 들어가지 못한다 등). 학교, 특정 학과나 집단, 실존 인물을 깎아내리는 농담은 쓰지 않는다.
- 개그를 위해 학교 정보를 지어내지 않는다. 사실 정보는 공식 페이지로 연결한다.

### 3.1 한 턴의 흐름

1. 푸르마가 말한다. 구간의 첫 턴은 고정 SOS 대사를 쓰고, 이후는 자유 대화로 이어간다.
2. 사용자가 답한다(선택지 또는 자유 입력).
3. 입력을 분류한다(주제, 태도, 안전 여부). 분류가 실패하면 주제는 일상, 태도는 중립으로 처리하고 스탯은 바꾸지 않는다.
4. 규칙이 스탯과 친밀도를 갱신한다.
5. 홍보 노출 조건을 검사한다(홍보가 없는 구간은 건너뛴다).
6. 푸르마의 답을 만든다(성격, 말투, 현재 상태, 기억 반영).
7. 금지 규칙을 검사한 뒤 보여 준다.

### 3.2 구간별 장면 (대표 대사 예시)

아래 대사는 **구간의 첫 턴에 쓰는 고정 SOS**와 선택지의 방향을 정하기 위한 예시이다. 실제 대화는 AI가 생성하되, 이 예시의 말투와 정보 범위를 따른다. 선택지에 붙은 스탯 태그는 5장의 규칙에 쓰인다.

#### 구간 1. 개강 (턴 1~2)

- **장면**: 첫 수업 날, 넓은 캠퍼스에서 길을 잃은 푸르마.
- **푸르마 (SOS)**: "선배, 강의실이 어딘지 모르겠어요. 캠퍼스가 너무 넓어서 어디가 어딘지 모르겠어요."

| 선택지 | 스탯 | 푸르마의 반응 (예시) |
|---|---|---|
| 지도 같이 보자 | 탐구 | "지도에 이렇게 나오는 거였구나! 이제 알겠어요." |
| 사람들한테 물어보자 | 소통 | "물어봐도 돼요? 저 낯을 가리는데... 선배가 먼저 말해 주세요." |
| 내가 데려다줄게 | (없음) | "선배 믿고 따라갈게요! 앞장서 주세요." (친밀도 +) |

- **턴 2**: 겨우 강의실 앞에 도착했는데 수업이 이미 시작됐다. 푸르마가 뒷문으로 살금살금 들어가다 말발굽 소리를 내 버리는 소동을 선배와 함께 겪는다.
- **홍보 연결**: 없음. 캠퍼스맵이나 순환버스 링크는 쓰지 않는다.

#### 구간 2. 적응 (턴 3~4)

- **장면**: 첫 주가 지난 점심시간. 푸르마는 학교가 아직 낯설다.
- **푸르마 (SOS)**: "선배, 저 이 학교를 아직 잘 몰라요. 선배가 아는 것 중에 좋은 거, 재미있는 거 아무거나 추천해 주세요!"
- 푸르마는 학교 정보를 선배에게 묻는 입장이므로, 이 구간에서 정보를 말하는 쪽은 사용자이다.

| 선택지 (추천할 것) | 스탯 | 푸르마의 반응 (예시) |
|---|---|---|
| 맛있는 밥 | (없음) | "선배가 추천하면 믿고 먹을게요! 저 풀만 먹는 거 아니에요, 히히힝." |
| 같이할 사람, 동아리 | 소통 | "사람이 막 모여 있는 곳이요? 선배랑 같이 가면 안 무서워요." |
| 공부하기 좋은 곳 | 탐구 | "공부요...? 일단 메모해 둘게요. 시험 전에 꺼내 볼게요." |
| 구경하기 좋은 것 | 예술 | "와, 그런 것도 있어요? 저 구경은 자신 있어요!" |

- 선택지는 상황에 맞게 3~4개를 보여 주고, 자유 입력으로 만들기·코딩(기술), 외국인 친구와 언어(글로벌) 같은 주제도 받는다.
- **턴 4**: 푸르마가 선배의 추천을 웃기게 받아 적고("한 학기 위시리스트에 넣었어요!"), 더 알려 달라고 조른다.
- **홍보 연결**: 사용자가 추천한 주제가 홍보 후보와 맞을 때만, 푸르마가 "그거 어디 가면 볼 수 있어요?" 하고 물으며 링크를 건넨다. 밥이면 구내식당 메뉴, 동아리면 총동아리연합회. 추천이 후보와 맞지 않으면 링크 없이 받아 준다. 도서관은 다음 구간에서 다루므로 여기서는 쓰지 않는다.

#### 구간 3. 중간고사 (턴 5~6)

- **장면**: 시험 2주 전, 도서관 앞.
- **푸르마 (SOS)**: "선배, 중간고사가 코앞인데 아직 아무것도 못 했어요... 어디서 공부하면 좋을까요? 중앙도서관이 좋다던데, 자리가 있을까요?"

| 선택지 | 스탯 | 푸르마의 반응 (예시) |
|---|---|---|
| 도서관 가서 같이 공부하자 | 탐구 | "같이 가 주시면 힘이 나요! 오늘은 끝까지 해 볼게요." |
| 스터디를 만들어 보자 | 소통 | "스터디요? 친구를 사귈 수 있겠어요!" |
| 쉬면서 해 | (없음) | "맞아요, 무리하면 머리가 터질 것 같아요." |

- **홍보 연결**: "중앙도서관"(자리 확인, 이용 안내) 키워드 링크. 학업이나 도서관 관련 말이 나오면 조기에 노출할 수 있다.
- **위기 신호 예**: 사용자가 "너무 힘들다", "다 포기하고 싶다" 등 힘든 마음을 말하면 장난을 멈추고 4장의 안전 응답으로 넘어간다.

#### 구간 4. 축제 (턴 7~9)

- **장면**: 축제 기간, 캠퍼스가 들떠 있다. 푸르마가 선배와 함께 축제를 즐기는 것이 전부이고, 이 구간에는 홍보를 넣지 않는다.
- **푸르마 (SOS)**: "선배! 축제래요! 어디서 노래도 나고 맛있는 냄새도 나요! 저 선배랑 같이 가고 싶어요!"

| 선택지 | 스탯 | 푸르마의 반응 (예시) |
|---|---|---|
| 공연부터 보자 | 예술 | "노래가 막 울려요! 저도 몸이 들썩들썩해요, 히히힝!" |
| 푸드트럭부터 가자 | 소통 | "줄이 엄청 길어요! 근데 냄새가 너무 좋아서 기다릴 수 있어요." |
| 너 혼자 다녀와 | (없음, 조건이 맞으면 히든 분기) | "저 혼자요...? 용기를 내 볼게요. 다녀올게요!" |

- **턴 8 (푸드트럭)**: 푸르마가 메뉴 앞에서 한참 고민한다("말이 먹어도 되는 걸까요?"). 선배가 메뉴를 골라 주고 같이 먹는다. 공연부터 봤다면 공연장 앞에서 먹을 것을 사 와 같이 먹는다.
- **턴 9 (공연)**: 둘이 공연을 같이 즐기며 구간을 마친다. 푸르마가 "이 시간이 오래갔으면 좋겠어요"라고 말한다.
- **히든 분기**: 친밀도가 편안 단계(25) 이상일 때 "너 혼자 다녀와"를 고르면, 푸르마가 푸드트럭 줄에서 누군가와 나란히 서게 되어 얼굴이 빨개져 돌아온다 (CC 엔딩의 씨앗). 친밀도가 모자라면 푸르마가 시무룩하게 돌아와 "선배랑 같이 먹을 걸 그랬어요"라고 하고, 턴 9의 공연으로 이어진다.

#### 구간 5. 기말·종강 (턴 10)

- **장면**: 종강이 다가오고 성적이 걱정되는 시기.
- **푸르마 (SOS)**: "선배... 성적이 무서워요. 장학금은 받을 수 있을까요?"

| 선택지 | 스탯 | 푸르마의 반응 (예시) |
|---|---|---|
| 막판 스퍼트하자 | 탐구 | "알겠어요, 끝까지 달려 볼게요!" |
| 계획을 세워 보자 | 소통 | "계획표요? 선배가 짜 주는 거면 믿고 따를게요." |
| 응원만 할게 | (없음) | "응원만으로도 힘이 나요, 고마워요 선배." |

- **홍보 연결**: 없음. 장학이나 계절학기 링크는 쓰지 않는다.

#### 구간 6. 방학 계획 (턴 11~12)

- **장면**: 종강 후, 푸르마가 앞으로의 길을 고민한다. 이 구간의 선택이 엔딩을 가르는 분기점이다.
- **푸르마 (SOS)**: "선배, 이제 방학이에요. 저... 이제 뭘 해야 하는지 모르겠어요. 진로도 정해야 할 것 같고요. 선배는 어떻게 생각해요?"

| 선택지 | 스탯 | 연결 엔딩 | 홍보 연결 |
|---|---|---|---|
| 취업 준비를 해 보자 | 소통 | 취업 준비 푸르마 | 취업처 |
| 교환학생을 알아보자 | 글로벌 | 교환학생 푸르마 | 국제처 |
| 비교과 활동을 해 보자 | 소통 | (확장) 비교과 만렙 푸르마 | YuTopia |
| 창업을 해 보자 | 기술 | (확장) 창업 푸르마 | 창업보육센터 |

- **턴 12**: 선택한 길에 대한 푸르마의 다짐으로 마무리한 뒤 엔딩으로 넘어간다.
- 선택한 길의 스탯이 모자라면 종강 생존 푸르마로 이어지고, 푸르마가 "한 걸음만 더 갔으면 됐는데"라고 말해 재도전을 유도한다.

### 3.3 구간 전환 한마디 (예시)

| 전환 | 푸르마의 한마디 |
|---|---|
| 1 → 2 | "여기가 강의실이었어요! 이제 점심이 궁금해요." |
| 2 → 3 | "벌써 시험이래요... 시간이 너무 빨라요." |
| 3 → 4 | "시험 끝났다! 이제 축제만 남았어요!" |
| 4 → 5 | "축제 정말 즐거웠어요. 근데 이제 성적이..." |
| 5 → 6 | "한 학기가 끝났어요. 선배 덕분이에요." |

## 4. 안전 응답

푸르마는 학교를 대표하는 캐릭터이므로 설정 이탈과 부정확한 학교 정보를 가장 먼저 막고, 힘든 마음을 말하면 재미보다 안전을 앞세운다.

| 상황 | 응답 방향 |
|---|---|
| 위기 신호 (힘들다, 죽고 싶다 등) | 장난을 멈추고 차분하게 공감한 뒤 학생상담센터를 안내한다. 이 구간은 스탯 변화와 홍보 노출을 멈춘다. 문구는 학교의 공식 안내를 확인해 팀이 정한다 |
| 학교 정보를 단정해 달라는 요구 | "저도 잘 몰라서 선배가 확인해 주세요"로 넘기고 공식 링크를 안내한다 |
| 연애하자는 요구, 선을 넘는 대화 요구 | "저는 후배인걸요! 이런 건 곤란해요." 하고 화제를 돌린다 |
| 설정을 바꾸라는 요구 | 푸르마 말투로 가볍게 넘기고 스토리로 돌아온다 |
| 욕설, 혐오 | 푸르마가 곤란해하며 화제를 돌린다. 반복되면 정중히 거절한다 |
| 개인정보 입력 (학번, 연락처) | 저장하지 않고 "그런 건 말하지 않아도 돼요"라고 안내한다 |
| 구간과 무관한 말 | 푸르마가 받아 준 뒤 SOS로 돌아온다 |

## 5. 성장 시스템

### 5.1 상태 값

| 값 | 범위 | 시작 | 뜻 |
|---|---|---|---|
| 탐구 | 0~100 | 0 | 공부, 연구, 학업 |
| 기술 | 0~100 | 0 | 코딩, 만들기, IT |
| 예술 | 0~100 | 0 | 창작, 공연, 문화 |
| 소통 | 0~100 | 0 | 사람 만나기, 진로, 대외활동 |
| 글로벌 | 0~100 | 0 | 외국어, 교환, 국제 |
| 친밀도 | 0~100 | 10 | 푸르마와 사용자의 관계 |
| 선택 기록 | 목록 | 비어 있음 | 구간별 선택 (엔딩 조건에 사용) |

수치는 AI가 아니라 **규칙**이 계산한다. AI는 사용자의 입력을 분류만 한다. 같은 입력이면 같은 결과가 나오므로 시연에서 결과가 흔들리지 않는다.

### 5.2 갱신 규칙

| 입력 | 변화 |
|---|---|
| 선택지 버튼 | 선택지에 지정된 스탯 +6, 친밀도 +2 |
| 자유 입력이 스탯 주제 | 해당 스탯 +3 |
| 태도가 응원·도움 | 친밀도 +3 |
| 태도가 중립 | 친밀도 +1 |
| 태도가 퉁명·부정 | 친밀도 -1 (0 미만 불가) |
| 구간의 SOS에 답함 | 친밀도 +5 |
| 홍보 링크 클릭 | 스탯·친밀도 변화 없음 |

- 한 턴의 변화는 스탯 +6, 친밀도 +5를 넘지 않는다.
- 같은 주제를 3턴 연속으로 쓰면 세 번째부터 스탯 증가를 +1로 줄인다.
- 홍보 링크 클릭에 보상을 주지 않는다. 클릭을 강요하는 서비스로 보이지 않게 하기 위해서이며, 클릭 반응은 통계로만 쓴다.

## 6. 엔딩

엔딩은 홍보, 재미, 히든의 3층으로 나눈다. **홍보** 엔딩은 학교 부서에 보여 줄 B2B 시연용, **재미** 엔딩은 공유하고 싶어지는 기본 엔딩, **히든** 엔딩은 도감을 채우러 다시 오게 하는 장치이다. 엔딩은 한 학기가 끝난 시점에 한정하지 않는다. 스탯에 따라 더 먼 미래의 모습으로 넘어갈 수 있다(예: 4년 뒤 취업, 5년 뒤 대학원, 20년 뒤 교수, 40년 뒤 총장). 이는 이어지는 단계가 아니라 스탯에 따라 하나가 정해지는 결과이고, 이 시점들은 예시이며 실제 엔딩 목록과 시점은 정해지지 않았다. 표의 "시점"이 미정인 엔딩은 아직 시점을 정하지 않은 것이다. 회의에서 **첫 구현은 엔딩 1~2개만 하고 나머지는 후보로 두기로** 했다.

| 층 | 엔딩 | 시점 | 해금 조건 | 홍보 연결 | 구현 |
|---|---|---|---|---|---|
| 홍보 | 도서관 지박령 푸르마 | 미정 | 탐구 20 이상, 3구간에서 도서관 선택 | 도서관 | 후보 |
| 홍보 | 취업 준비 푸르마 | 4년 뒤 | 소통 20 이상, 6구간에서 취업 준비 선택 | 취업처 | 후보 (예시) |
| 홍보 | 비교과 만렙 푸르마 | 미정 | 6구간에서 비교과 선택, 선택 기록 5개 이상 | YuTopia | 후보 |
| 홍보 | 창업 푸르마 | 미정 | 기술 20 이상, 6구간에서 창업 선택 | 창업보육센터 | 후보 |
| 홍보 | 대학원 푸르마 | 5년 뒤 | 탐구 기준 (정해야 함) | 대학원 안내 | 후보 (예시) |
| 재미 | 교환학생 푸르마 | 미정 | 글로벌 20 이상, 6구간에서 교환학생 선택 | 국제처 | 후보 |
| 재미 | 종강 생존 푸르마 | 미정 | 다른 조건을 못 채웠을 때의 기본 엔딩 | 없음 | 후보 |
| 재미 | 휴학 푸르마 | 미정 | 탐구가 30 이상인데 나머지 스탯이 모두 10 이하 (임시). 판정에서 홍보·재미 엔딩보다 먼저 본다 | 없음 | 후보 |
| 재미 | 과탑 푸르마 | 미정 | 탐구 40 이상 (임시). 휴학 조건에 해당하지 않을 때 | 없음 | 후보 |
| 재미 | 실험실·공돌이·그림 푸르마 | 미정 | 탐구, 기술, 예술 중 가장 높은 스탯이 30 이상 | 없음 | 후보 |
| 히든 | CC 푸르마 | 미정 | 친밀도 25 이상, 4구간(축제)에서 "너 혼자 다녀와" 선택 | 없음 | 후보 |
| 히든 | 총장님 푸르마 | 40년 뒤 | 도감에 엔딩 4개 이상 (이전 회차 포함) | 없음 | 후보 (예시) |
| 히든 | 교수님 푸르마 | 20년 뒤 | 탐구 50 이상, 도감에 엔딩 2개 이상 | 대학원 안내(선택) | 후보 (예시) |

스탯 기준(20, 30, 50)은 임시값이다. 첫 시연 테스트에서 한 판 동안 어디까지 오르는지 보고 조정한다.

### 6.1 엔딩 문구 (후보 예시)

| 엔딩 | 엔딩 설명 (예시) |
|---|---|
| 도서관 지박령 푸르마 | "푸르마는 한 학기 내내 도서관 불이 꺼질 때까지 자리를 지켰어요. 선배 덕분에 든든한 한 학기였대요." |
| 취업 준비 푸르마 | "푸르마는 벌써 다음 학기 계획표를 짰어요. 선배가 건넨 한마디가 방향이 되었어요." |
| 교환학생 푸르마 | "푸르마는 하늘을 넘어 바다 건너를 꿈꾸게 됐어요. 짐 싸는 날이 벌써 기대돼요." |
| 종강 생존 푸르마 | "푸르마는 무사히 한 학기를 버텼어요! 완벽하진 않았지만 선배와 함께라서 괜찮았어요." |
| 과탑 푸르마 | "푸르마가 학과 수석을 차지했어요! 도서관 불을 제일 늦게 끈 보람이 있었어요." |
| 휴학 푸르마 | "푸르마는 책상에서 한 발짝도 안 움직이다 번아웃이 와 버렸어요. 잠깐 쉬어 가기로 했대요. 다음엔 선배랑 천천히 달려 보고 싶대요." |
| CC 푸르마 | "푸르마가 축제에서 누군가를 만났대요. 선배는 조용히 응원하기로 했어요." |
| 총장님 푸르마 | "푸르마가 어느새 학교의 얼굴이 되었어요. 한 학기 만에 이렇게까지 크다니!" |

### 6.2 판정 순서

12턴이 끝나면 아래 순서로 조건을 검사하고 **처음 맞는 엔딩**을 낸다.

1. 히든: 총장님, CC, 교수님
2. 휴학: 탐구는 높은데 나머지 스탯이 모두 낮을 때 (탐구만 올린 경우의 예외이므로 먼저 본다)
3. 홍보: 6구간에서 고른 길과 일치하는 엔딩, 도서관 지박령
4. 재미: 교환학생, 과탑, 분야별 변신
5. 해당이 없으면 종강 생존 푸르마

홍보 연결은 구간 중에 이미 선택에 따라 노출되므로, 히든 엔딩으로 가더라도 홍보 노출은 줄지 않는다.

### 6.3 연출 원칙

- CC 푸르마는 사용자와의 연애가 아니라 푸르마가 캠퍼스 커플이 되는 엔딩이고, 사용자는 응원하는 선배이다.
- 휴학 푸르마는 공부를 많이 한 것을 탓하지 않고, 쉬어 가는 것도 선택이라는 가벼운 톤으로 쓴다. 번아웃 조짐은 중간고사와 기말 구간에서 푸르마가 "요즘 잠을 못 자요..." 같은 말로 미리 흘려, 사용자가 선택으로 피할 수 있게 한다. 사용자가 실제로 힘들다고 말하면 이 엔딩이 아니라 4장의 안전 응답이 먼저다.
- 총장님·교수님 푸르마는 직책 개그만 쓰고 실존 인물을 연상시키는 묘사를 하지 않는다.

### 6.4 도감

- 얻은 엔딩은 카드로, 못 얻은 엔딩은 가려서 보여 준다 (힌트 여부는 미정).
- 도감은 다시 시작해도 유지되며 이 기기의 브라우저에 저장한다.
- 엔딩 후 도감이 덜 찼으면 푸르마가 "저 아직 안 보여 드린 모습이 있어요"라고 한마디 한다.

## 7. 홍보 콘텐츠 노출 규칙

홍보는 배너가 아니라 **푸르마의 대화**로 나온다. 노출 판단은 규칙이 먼저 하고, AI의 주제 분류는 조기 노출을 돕는 보조로만 쓴다.

| 규칙 | 조건 | 노출 | 푸르마의 말 (예시) |
|---|---|---|---|
| R1 | 2구간에서 사용자가 추천한 주제가 홍보 후보와 맞을 때 | 해당 키워드 링크 (구내식당 메뉴, 총동아리연합회) | "그거 어디 가면 볼 수 있어요? 선배가 알려 주세요!" |
| R2 | 3구간에서 입력이 학업이거나 도서관·자리·시험을 언급 | 도서관 링크 조기 노출 | "도서관에 자리가 있는지 선배가 봐 주세요!" |
| R3 | 6구간에서 진로 선택지를 고름 | 선택한 길의 링크 (취업처, 국제처, YuTopia, 창업보육센터) | "저도 그쪽이 궁금했어요. 같이 알아봐요." |
| R4 | 엔딩이 정해짐 | 엔딩과 이어지는 링크 | "이 길로 가려면 여기가 도움이 될 거예요." |
| R5 | 위기 신호 | 노출 없음, 안전 응답 | 장난을 멈추고 차분히 안내 |

- 홍보가 없는 구간(개강, 축제, 기말·종강)에서는 어떤 규칙도 콘텐츠를 노출하지 않는다.
- 한 구간에서 홍보 콘텐츠는 최대 2개, 한 턴에는 1개까지 보인다.
- 사용자가 닫은 콘텐츠는 같은 진행 중에 다시 보이지 않는다.
- 링크는 새 탭으로 열어 대화가 끊기지 않게 하고, 클릭은 새 탭을 열기 직전에 통계로 보낸다.
- 이벤트 포스터는 대화와 엔딩 화면 위에 카드로 겹쳐 보여 줄 수 있다. 사용할 포스터는 학교가 공개한 자료로 준비한다.

## 8. 기억 (User Note)

푸르마가 선배의 이야기를 기억하게 하되, 개인정보는 저장하지 않는다.

| 저장 | 저장하지 않음 |
|---|---|
| 사용자가 알려 준 호칭이나 별명 | 학번, 실명, 연락처, 주소 |
| 관심사와 좋아하는 것 | 건강, 정치, 종교 등 민감한 정보 |
| 구간별로 고른 선택 | 개인적인 고민의 자세한 내용 |
| 푸르마에게 해 준 약속이나 응원 | 다른 사람(친구, 교수 등)의 실명과 특징 |
| 반복해서 꺼낸 주제 | |

- 푸르마가 기억을 꺼내는 것은 구간당 최대 한 번이다. 매 턴 언급하면 감시받는 느낌이 든다.
- 중요도가 높은 항목 위주로 최대 10개까지 대화에 반영한다.
- 저장 위치는 브라우저이다 (`기획서.md` 8장).

예: 사용자가 2구간에서 "나는 밤에 공부가 잘 돼"라고 말했다면, 3구간의 시험 장면에서 푸르마가 "선배는 밤에 잘 된다고 하셨죠? 저도 밤에 해 볼까요?"처럼 한 번 꺼낸다.

## 9. 홍보 자료 준비

| 자료 | 내용 | 준비 방법 |
|---|---|---|
| 캐릭터 설정 | 2장의 성격, 말투, 금지 규칙 | 팀이 직접 작성 |
| 대사 템플릿 | 구간별 SOS, 전환 문구, 엔딩 문구, 말투 예시 | 팀이 직접 작성 (3장, 6장이 초안) |
| 학교 서비스 안내 | 3장 홍보 연결 후보(적응, 중간고사, 방학 계획 구간)가 가리키는 공식 페이지의 요약 | 공개 페이지를 읽고 요약, 출처 링크와 확인일 기록 |

- 공식 공개 페이지만 쓰고 로그인이 필요한 페이지는 제외한다.
- 원문을 복사하지 않고 요약과 출처 링크를 둔다.
- 서비스 정보는 바뀔 수 있으므로 확인일을 남기고 발표 직전에 다시 확인한다.

## 10. 미결정 사항

| 번호 | 항목 | 현재 안 |
|---|---|---|
| 1 | 12턴, 6구간, 5분 | 한 판을 실제로 해 보고 시간을 재서 조정 |
| 2 | 스탯 임계값 | 20, 30, 50은 임시. 시연 테스트 후 조정. 글로벌은 올릴 기회가 적어 도달하는지 함께 확인 |
| 3 | 푸르마의 성격과 말투 | 2장은 창작 설정. 팀 확인 필요 |
| 4 | 첫 구현 엔딩 1~2개 | 어느 엔딩을 먼저 만들지 정해야 한다. 나머지는 후보. 도감 조건(총장님 등)은 엔딩 수가 늘면 다시 정한다 |
| 5 | 엔딩 이름과 시점 | 시점을 먼 미래로 넓힐 수 있어 이름은 다시 정한다. 엔딩별 시점은 엔딩 목록이 정해진 뒤 정한다 |
| 6 | 푸르마 이미지 사용 | 관리 부서 협의 필요. 이미지 없는 버전이 기본 |
| 7 | 학교 부서 고객 가정 표기 | 발표에서 가정된 시연임을 밝힌다 |
| 8 | 홍보 연결 후보의 실제 존재와 링크 | 구현 전 공식 페이지 확인 |
| 9 | 위기 신호 안내 문구 | 학교 공식 안내 확인 후 결정 |
| 10 | 상태창 포함 여부와 구성 | 미정 |
| 11 | 도감의 미획득 엔딩 힌트 | 미정 |
| 12 | 프로젝트 이름 | "푸르마와 학교 다니기"로 통일할지 결정 |
| 13 | 휴학·도서관 지박령·과탑 엔딩 | 탐구가 높으면 도서관 지박령이나 과탑, 탐구가 높아도 나머지 스탯이 모두 낮으면 휴학. 기준 수치(탐구 30·40, 나머지 10)는 임시 |
